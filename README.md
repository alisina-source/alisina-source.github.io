# Ali — Professional Portfolio

Public portfolio: https://alisina-source.github.io

Management runs in Ali's private Windows app and publishes directly to this GitHub repository. There is no public management form. Only repository writers can publish changes.

To back up the public portfolio, select Code → Download ZIP. Keep the private Windows manager separately and never upload its access token or session data here. The GitHub token is held in the manager process memory only.

website-source.zip contains the public website source, not the private manager. Before rebuilding, download the latest portfolio.json and any new media from the repository into public/portfolio.json and public/media. Run npm install and npm run build.
